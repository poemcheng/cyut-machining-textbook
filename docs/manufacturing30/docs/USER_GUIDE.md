# 安裝與使用手冊

## 安裝與啟動

本課程為靜態網站，無後端、資料庫、API 金鑰或個資登入。使用支援 WebGL 的瀏覽器；3D 需硬體加速或可用的軟體 WebGL。驗收環境為 GitHub Actions 的 Chromium；不同實體裝置仍需課前試用。

下載完整 ZIP 並解壓縮，安裝 Python 3。在教材資料夾開啟終端機，Windows 執行 `py -m http.server 8000`，macOS/Linux 執行 `python3 -m http.server 8000`。開啟 `http://localhost:8000`。亦可使用附帶的啟動腳本。不要以 file:// 或直接雙擊 HTML 開啟，ES modules 必須經 HTTP 供應。

正式版本與下載套件內有 vendor/three.module.js、vendor/controls/OrbitControls.js 及 LICENSE-THREE.txt，版本固定為 0.164.1。啟動後不必連線外部 CDN。來源連結需網路，但不影響離線教學功能。維護者可執行 npm install 取得開發依賴；學生不必安裝 Node.js。

## 學生流程

左側選章；手機使用右上角「章節」。先讀觀念、公式與適用限制，再調整有工程單位的滑桿或數值欄。超出允許範圍時顯示錯誤並保留上一組有效結果。軋延出口厚度必須小於入口厚度。按「還原預設」可恢復。

3D 可拖曳旋轉、滾輪或雙指縮放、重設視角、線框與視覺剖切。播放是示意階段，不是實機加工時間；右側計算仍對應完整輸入條件。變形、間隙與鍍層可能放大，不應以畫面像素量尺寸。剖切是顯示用 clipping plane，不是幾何實體切割或封口求解。

「實驗與比較」先填預測，擷取 A。修改指定參數後擷取 B，引用兩組數值與單位說明觀察，最後寫限制與遷移。兩組參數必須不同，三段文字各至少五字。這是紀錄完整性檢查，並非文字正確性的自動評分。重新擷取 A/B 會取消先前的實驗完成狀態，需要重新儲存。

「自我評量」每章兩題概念、一題計算。計算題凍結出題當時參數，調參不會偷偷改答案；按重新出題才使用新條件。計算容許 2% 相對誤差，接近零時以 0.0001 絕對誤差為底線。每章記錄最高答對題數。答案存在前端程式，僅適合形成性練習，不應當作保密考試。

已瀏覽不等於已完成。完成標記需要儲存實驗且最高答對至少兩題；並非證明學生能安全操作實機。

## 保存、匯出與教師彙整

匿名代碼可在學習紀錄中修改。不要填姓名、學號或敏感資訊。資料只存在目前瀏覽器 localStorage，換裝置、無痕模式、清除網站資料或儲存限制均可能造成遺失；系統沒有雲端復原或學生進度匯入功能。

下課前匯出 JSON 並依教師指定方式繳交。JSON 含 A/B、參數、輸出、文字解釋、最高分與事件；CSV 為章節摘要。事件最多保留最近 1000 筆，章節最後狀態另行保存，故不可將事件檔視為無限完整的研究歷程。

教師可選取多份 JSON，在本機檢視瀏覽、實驗、平均最高分與完成章數。單檔最多 2 MB、單次最多 100 份；同人不同檔案分列、不自動合併、不修改教師自己的進度，也不傳到雲端。平均分只針對已作答章節的最高分，不是全課平均或前後測成效。

建議以預測、單位與計算、比較證據、限制、遷移各 0–2 分人工評閱，共 10 分。學生作答與自陳紀錄可修改，平台沒有防竄改或身分驗證。

## 常見問題

3D 空白但文字正常：確認硬體加速與 WebGL，檢查 vendor 目錄及 import map。從完整套件重新解壓縮，勿只複製 index.html。

整頁無章節：確認透過 HTTP 啟動、src/chapters 三個檔案齊全，開啟開發者工具查看載入錯誤。

紀錄消失：檢查是否更換主機名稱、連接埠、瀏覽器或無痕視窗，這些可能屬不同儲存來源。教師仍可閱讀先前匯出 JSON。

手機操作：右上展開章節，參數區位於 3D 下方。觸控場景的手勢可能與瀏覽器縮放不同。尚未實測所有手機 GPU。

## 範圍與安全

每章完成一個代表性互動實驗及其學習流程，不是原書全文或所有設備的多物理模擬。預設數值是教學假設，不能作為加工、熱處理、電氣、壓力或焊接設備的實機設定。操作真機需依原廠手冊、場域規範及教師監督。


## 4.0 場域、原廠案例與官方機器人

1. 選章後，畫面自動切換到對應的代表性場域。上方四個流程按鈕標示原料、製程與檢驗的關係；不代表實際安全搬運路徑。
2. 「場域總覽」觀察周邊配置，「設備近看」聚焦設備；「顯示場域」可隱藏周邊。
3. 原廠案例選單提供真實品牌及系列、來源網址與差異。更換案例卡不會把通用幾何變成該型號 CAD；右側數值仍是教學解析模型。
4. 第 1、25、28、29 章可切換官方 UR5e 與 TM5-900。模型來源是廠商公開 VISUAL 網格，七個連桿依名義關節鏈組裝；不是外觀重新手繪，也沒有以低精度碰撞模型代替。
5. 以 J1–J6 滑桿調整角度；tool0 顯示的是來源 base_link 座標的毫米值，未加裝工具、未做單機校正。UR 的 base_link 與控制器 Base 原點朝向有差異，不能直接複製為控制器座標。
6. 「展示姿態」與「名義零位」只是數學姿態，不保證無碰撞。勾選隨進度示範後，再按原有播放鈕；它不是可下發控制器的軌跡。
7. 第 29 章右側原有平面二連桿算例與六軸官方模型不同。分別比較模型假設，不要將兩者的末端數值混用。
8. 點選官方模型可顯示來源連桿名；構件標註會顯示工具座標軸。外殼透視只作用於通用機台，官方模型可用線框觀察。
9. 案例選取、流程按鈕及關節調整加入原有匿名 JSON events；匯出及原有實驗／評量流程維持不變，沒有雲端蒐集。

### 離線與瀏覽器

正式離線包含所有約 17 MB 的官方轉換網格與授權，不須外部 CDN；仍需以 HTTP localhost 執行。官方網格以 SHA-256 校驗，因此需 HTTPS 或 localhost 的安全來源。用區網 HTTP IP 開啟不支援 crypto.subtle 的瀏覽器時，應改用 HTTPS。首次選取兩款機器人需載入各自資產；較弱的內顯可隱藏場域、關閉線框並縮小畫面。
