# 18 週課程與評量建議

這是可調整的教學安排，未宣稱已實施或驗證成效。每週採預測、操作、計算、比較、限制與遷移流程。

|週|章節|主要任務與證據|
|---|---|---|
|1|1|製造轉換、批量與成本；前測與 A/B 成本表|
|2|2–3|材料、剛性與強度；單位、樑變形與降伏邊界|
|3|4|尺寸公差、表面及配合；最差組合推理|
|4|5–6|鑄造、冒口；尺寸效應與利用率折衷|
|5|7–8|玻璃與塑料；守恆、鎖模力與流量|
|6|9–11|複材、粉末與陶瓷；混合模型、壓實、收縮|
|7|12–13|金屬成形、軋延；應變、流動與厚度限制|
|8|14|鈑金；中性層、彎曲裕量與展開長度|
|9|1–14|期中：製程選擇與模型邊界|
|10|15–16|切削與機具；剪切角、轉速、時間、MRR|
|11|17–18|刀具與輪磨；壽命敏感度、砂輪周速|
|12|19–21|非傳統加工、熱處理、表面；能量、冷卻、電量|
|13|22–23|電弧與點焊；淨熱輸入與 I²Rt 的差異|
|14|24–25|接合與組裝；搭接應力、預緊力、摩擦不確定性|
|15|26–27|快速成型與微製造；層高、解析度與焦深|
|16|28–29|生產系統及自動化；瓶頸改善、2R 運動學|
|17|30|品質能力；穩定性、規格與管制界限|
|18|1–30|跨章專題、後測與遷移任務|

章節自評可重作，不宜作為唯一成績。A/B 學習單以預測、計算與單位、證據比較、限制、遷移各 0–2 分人工評閱。跨章專題應連結選材、製程、接合、檢測與產能，並交代計算來源與限制。

教學實踐研究需另設等值前後測、未見過的遷移題、評分者一致性及學生同意程序。點擊量、完成率或最高分不能單獨證明成效，更不能直接宣稱因果改善。
