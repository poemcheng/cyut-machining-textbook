# 製造程序 30 章：機械機構重建與驗收界線

## 本次實作

30 章各自配置一座程序化 Three.js 工業機械設備，呈現機台床身、主軸、導軌、螺桿、夾具、模具、馬達、液壓、機罩、控制面板等相關機構。模型具有零件階層、PBR 金屬材質、陰影、定性運動、零件點選與名稱、線框、外殼透視、原理示意切換，並保留工程參數、計算與形成性評量。

**模型等級：原創教學級工業機構重建。** 非特定廠牌／型號的 OEM CAD；尺寸正規化，未經原廠裝配圖、實機量測、運動極限或干涉檢查校正。動畫不是 CAE、多體動力學或實機安全驗證。

## 進階真實機械數位孿生驗收

若要達到與實際設備一致的機械工程等級，需由設備商或校內實驗室提供有使用授權的 STEP／IGES／SolidWorks/CATIA 裝配模型、BOM、關節座標、軸行程、刀具與治具、實機照片、尺寸公差及原廠手冊。CAD 匯入 FreeCAD 或 Blender 後，保留零件階層與座標系輸出 GLB；逐項校核外形、關節零點、運動方向、干涉、LOD、效能與安全警示。無上述證據不得宣稱特定型號 1:1 精度或安全可用。

## 實作與測試

- `src/industrial.mjs`：30 個設備分件場景、傳動／送料動畫、材質與構件名稱。
- `src/scenes.mjs`：工業設備／原理剖面雙視圖、射線選取、線框、外殼透視、光照與陰影。
- `tests/browser.mjs`：30 章 WebGL、構件數、動作通道、模式切換、評量與學習紀錄測試。
- `src/models.mjs`：工程解析模型與單位，與示意動畫分離。

**教學用途限定：** 不可直接依畫面或動畫設定真實機台加工條件。
